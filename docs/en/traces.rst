The dist_emaj_hist Table
------------------------

All significant operations performed by Distributed E-Maj are logged in the *dist_emaj_hist* table.

Any user with *dist_emaj_adm* or *dist_emaj_viewer* privileges can view the contents of the *dist_emaj_hist* table.

Table Structure
^^^^^^^^^^^^^^^

The structure of the **dist_emaj_hist** table is as follows.

+---------------+-------------+---------------------------------------------------------------------------+
| Column        | Type        | Description                                                               |
+===============+=============+===========================================================================+
| hist_id       | BIGSERIAL   | Serial number identifying a row in this history table                     |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_datetime | TIMESTAMPTZ | Date and time when the row was recorded                                   |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_function | TEXT        | Function associated with the event                                        |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_event    | TEXT        | Type of event                                                             |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_object   | TEXT        | Name of the object the event relates to (group, table, sequence, etc.)    |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_wording  | TEXT        | Additional comments                                                       |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_user     | TEXT        | Role that triggered the event                                             |
+---------------+-------------+---------------------------------------------------------------------------+
| hist_txid     | BIGINT      | Transaction number that triggered the event                               |
+---------------+-------------+---------------------------------------------------------------------------+

The *hist_function* Column
^^^^^^^^^^^^^^^^^^^^^^^^^^

The *hist_function* column can take the following values.

+----------------------------------+------------------------------------------------------------------------------------------+
| Value                            | Meaning                                                                                  |
+==================================+==========================================================================================+
| ASSIGN_GROUP                     | Assignment of a group to a cluster                                                       |
+----------------------------------+------------------------------------------------------------------------------------------+
| CREATE_CLUSTER                   | Creation of a cluster                                                                    |
+----------------------------------+------------------------------------------------------------------------------------------+
| CREATE_DATABASE                  | Creation of a database                                                                   |
+----------------------------------+------------------------------------------------------------------------------------------+
| DELETE_BEFORE_MARK_CLUSTER       | Deletion of distributed marks prior to a mark for a cluster                              |
+----------------------------------+------------------------------------------------------------------------------------------+
| DIST_EMAJ                        | Execution of a distributed function (start, stop, set_mark) for a cluster                |
+----------------------------------+------------------------------------------------------------------------------------------+
| DIST_EMAJ_INSTALL                | Installation or version update of Distributed E-Maj                                      |
+----------------------------------+------------------------------------------------------------------------------------------+
| DROP_CLUSTER                     | Deletion of a cluster                                                                    |
+----------------------------------+------------------------------------------------------------------------------------------+
| DROP_DATABASE                    | Deletion of a database                                                                   |
+----------------------------------+------------------------------------------------------------------------------------------+
| IMPORT_CLUSTERS                  | Import of a *clusters* and *databases* configuration                                     |
+----------------------------------+------------------------------------------------------------------------------------------+
| IMPORT_PARAMETERS                | Import of a parameters configuration                                                     |
+----------------------------------+------------------------------------------------------------------------------------------+
| PURGE_HISTORIES                  | Deletion of events from *dist_emaj_hist* table older than the retention period           |
+----------------------------------+------------------------------------------------------------------------------------------+
| REMOVE_GROUP                     | Removal of a table group from its cluster                                                |
+----------------------------------+------------------------------------------------------------------------------------------+
| ROLLBACK_GROUPS                  | Execution of a distributed rollback for a cluster                                        |
+----------------------------------+------------------------------------------------------------------------------------------+
| SET_PARAM                        | Change of a Distributed E-Maj parameter value                                            |
+----------------------------------+------------------------------------------------------------------------------------------+
| SYNC_MARKS_CLUSTER               | Synchronization of local marks of a cluster's table groups                               |
+----------------------------------+------------------------------------------------------------------------------------------+
| VERIFY_CLUSTER                   | Verification of the state of a cluster                                                   |
+----------------------------------+------------------------------------------------------------------------------------------+

The *hist_event* Column
^^^^^^^^^^^^^^^^^^^^^^^

The *hist_event* column can take the following values.

+------------------------------+------------------------------------------------------------------------+
| Value                        | Meaning                                                                |
+==============================+========================================================================+
| BEGIN                        | Start                                                                  |
+------------------------------+------------------------------------------------------------------------+
| CLUSTER_CREATED              | *Cluster* created                                                      |
+------------------------------+------------------------------------------------------------------------+
| CLUSTER_DROP                 | *Cluster* dropped                                                      |
+------------------------------+------------------------------------------------------------------------+
| DATABASE_CREATED             | E-Maj *database* created                                               |
+------------------------------+------------------------------------------------------------------------+
| DATABASE_DROP                | E-Maj *database* dropped                                               |
+------------------------------+------------------------------------------------------------------------+
| DATABASE_UPDATED             | E-Maj *database* attributes changed                                    |
+------------------------------+------------------------------------------------------------------------+
| CLEANUP_RLBK_STATE           | Cleanup of rollback state                                              |
+------------------------------+------------------------------------------------------------------------+
| END                          | End                                                                    |
+------------------------------+------------------------------------------------------------------------+
| EXEC                         | Start of the execution phase of a distributed function                 |
+------------------------------+------------------------------------------------------------------------+
| GROUP_ASSIGNED               | Table group assigned to a *cluster*                                    |
+------------------------------+------------------------------------------------------------------------+
| GROUP_REMOVED                | Table group removed from a *cluster*                                   |
+------------------------------+------------------------------------------------------------------------+
| INIT                         | Start of the initialization phase of a distributed function            |
+------------------------------+------------------------------------------------------------------------+
| LOCK                         | Start of the locking phase of a distributed function                   |
+------------------------------+------------------------------------------------------------------------+
| MARKS DELETED                | Marks deleted                                                          |
+------------------------------+------------------------------------------------------------------------+
| PARAMETER DELETED            | Parameter deleted from *dist_emaj_param*                               |
+------------------------------+------------------------------------------------------------------------+
| PARAMETER INSERTED           | Parameter inserted into *dist_emaj_param*                              |
+------------------------------+------------------------------------------------------------------------+
| PARAMETER UPDATED            | Parameter modified in *dist_emaj_param*                                |
+------------------------------+------------------------------------------------------------------------+
| RESOLVE_MARK                 | Resolution of a distributed mark name                                  |
+------------------------------+------------------------------------------------------------------------+
| TIME STAMP SET               | Internal timestamp recorded                                            |
+------------------------------+------------------------------------------------------------------------+

----

E-Maj Databases
---------------

Each E-Maj database logs the elementary operations that concern it on its own side. (See the E-Maj documentation).
